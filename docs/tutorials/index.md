# Tutorials

Learning-oriented guides. Work through these in order if Drupdater is new to you — each
one is a complete, self-contained exercise with a concrete result at the end.

If you already know what you want to achieve, the [how-to guides](../how-to/index.md)
are the faster route.

<div class="grid cards" markdown>

-   **[Your first run](first-run.md)**

    ---

    Run Drupdater locally against a throwaway clone, with no token and no risk of
    changing anything remote. You will read the log, produce a run report, and
    understand what a real run would have pushed.

-   **[Scheduled updates in CI](scheduled-updates.md)**

    ---

    Go from nothing to a pull request arriving every Monday morning: validate the
    project, commit a `.drupdater.yaml`, and add the weekly and daily-security jobs.

</div>
